Hi, I'm Anirudh, a Senior Software Engineer with over 6 years of experience building Python based backend systems, REST APIs, cloud native applications and enterprise software. My work today is focused on Applied AI: designing and building AI powered software using large language models, modern AI frameworks and production engineering practices.

I care about the part that comes after the demo. Getting a model to produce something impressive once is straightforward. Making it reliable, validated, deployable and genuinely useful inside a real workflow is the engineering problem, and that is the problem I like to solve.

## My Journey

I started with a Bachelor's degree in Computer Engineering from the University of Mumbai, then completed an M.S. in Computer Science (Data Science) at the University of North Carolina at Charlotte.

Since then I have built production software for enterprise banking clients, for a university research lab on Google Cloud Platform, and for a Fortune 500 energy company where I owned Python applications and internal platforms end to end. Today I work independently on AI engineering and software development, building LLM powered applications from architecture through deployment.

## What I Build

My work sits where language models meet real software systems. That means backend services and REST APIs in Python and FastAPI, Retrieval Augmented Generation and vector based retrieval, agent workflows, and structured generation constrained by JSON Schema and validated with Pydantic so model output can be trusted by the code that consumes it.

It also means the unglamorous parts that decide whether an AI feature survives contact with production: local model inference and quantization when privacy or cost rules out an external API, automated verification tests, containerized deployment with Docker, and CI/CD pipelines on Azure and Google Cloud Platform.
